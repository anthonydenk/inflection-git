# Design exploration record

How the current site was designed: industry research, five San Francisco concept
directions, three structural variants of the winner, generated photography, and
the polish passes. Kept so any decision can be revisited or reversed.

Start with `DECISIONS.md` (every round, what was chosen, and why) and
`COPY-SOURCE.md` (the verbatim inflectioncm.com copy that governs every page).

Deliberately not committed here: `assets/plates/*.png` (about 66 MB of raw 2K
generation candidates) and `research/` (about 12 MB of reference screenshots).
The four chosen plates ship optimized as JPEG in `public/media/plates/`; the raw
candidates live in the design-iterations history on the `development2.0` branch
of the InflectionCapitalManagement repo if a re-grade is ever needed.
